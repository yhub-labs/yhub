# Y-Hub icon

**A Y-shaped hub**: three rounded tiles arranged in a Y topology — two upper arms and one lower stem.

- **Y** is the first letter of Y-Hub; the arms meet at the stem, reading as "many sources converge into one".
- **Tiles** are the product's own visual language (dashboard cells, one panel per tool), and keep the mark from looking like a thin typographic Y.
- The stem tile is a lighter moss color, guiding the eye from "two paths merge into one" — naturally forming a Y.

The geometry is defined entirely in this repository; there is no third-party artwork.

**Relation to the product**: Y-Hub exposes the same declaration on three faces — HTTP / MCP / CLI — from
one local backend. Two arms plus one stem is an abstract drawing of that topology.
